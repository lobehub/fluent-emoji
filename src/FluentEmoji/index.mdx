## Styles

Set `type` to choose the style. The image is loaded lazily from the CDN chosen by `cdn` (`aliyun`, i.e. npmmirror, by default, or `unpkg`).

| `type`   | Asset                                  |
| -------- | -------------------------------------- |
| `anim`   | Animated WebP                          |
| `3d`     | WebP (default)                         |
| `modern` | SVG                                    |
| `flat`   | SVG                                    |
| `mono`   | Monochrome SVG                         |
| `pure`   | No image, renders the native character |

## Fallback

With `type="pure"`, or when the image fails to load, the component renders the emoji character itself in a `size`-sized box, so a missing asset never shows a broken image.

## Custom image component

The image is rendered with `as` (default `img`) and receives `src`, `alt`, `width`, `height`, `loading="lazy"` and `unoptimized`, so it can be swapped for `next/image`:

```tsx
import { FluentEmoji } from '@lobehub/fluent-emoji';
import Image from 'next/image';

export default () => <FluentEmoji as={Image} emoji={'🤯'} size={64} unoptimized />;
```
