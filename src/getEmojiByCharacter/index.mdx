## getEmojiNameByCharacter

Returns the name of the first emoji in the input (from `@lobehub/emojilib`), or `undefined` if there is no emoji or no name for it.

```tsx
import { getEmojiNameByCharacter } from '@lobehub/fluent-emoji';

export default () => {
  const name = getEmojiNameByCharacter('🤯');

  return name;
};
```

## getEmoji

Returns the first emoji found in a string, or `undefined` if there is none.

```tsx
import { getEmoji } from '@lobehub/fluent-emoji';

export default () => {
  const emoji = getEmoji('🤯 in string');

  return emoji;
};
```
